Install on your Galaxy Watch7
  1. Download the release APK above. This is installed directly on your watch, not opened on your phone. Install Android SDK platform-tools on your computer.
  2. On the watch, enable Developer options, then ADB debugging and Wireless debugging.
  3. Choose Pair new device. Run adb pair WATCH_IP:PAIRING_PORT and enter the pairing code.
  4. Run adb connect WATCH_IP:CONNECTION_PORT, using the connection port from the watch's main Wireless debugging screen.
  5. Run adb install -r SignalWatch-release.apk. Open SignalWatch and choose Try demo or Connect on phone. Scan the code with your phone, sign in there, and approve the watch.
  6. Turn off wireless debugging when finished. This app is a development starter and has not yet been tested on your physical watch.

Live mode uses phone-approved pairing with your existing Signal account. The watch never asks for a password. The original debug build uses a different signing key; uninstall it before installing this direct release APK. Screen-off audio, downloaded briefings and the Signal unread complication work independently of Firebase. Native news and disaster reports require the phone companion and a server configured for Firebase; see the companion setup page.
